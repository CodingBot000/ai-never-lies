## 결론

이 게임의 가장 강한 플레이는 **서로 다른 기록이 같은 사건을 어떻게 다르게 설명하는지 발견하고, 그 판단을 심리에서 입증하는 것**이다. 승객이 기억한 무반응과 영상에 기록된 경고를 대조하는 장면은 이 경험을 짧게 보여준다. 회사 자료의 출처 대조, 사고 조건이 빠진 시험표, 두 안전장치의 반사실 비교도 같은 종류의 재미를 줄 수 있다.

이 재미를 가리는 문제가 세 가지다. 일부 선택은 후속 대사가 재생되지 않고, 두 곳은 정상 UI 입력으로 진행이 잠긴다. 목표·힌트·퍼즐 화면이 정답을 먼저 말해 조사할 이유를 줄인다. 새로 만든 가설과 근거를 다음 면담으로 가져가는 장면이 드물고, 후반에는 다시 입력하는 양이 늘어난다. 43개 장면 중 41개가 본선에 필요하고 20개 퍼즐이 같은 본선에 들어간다. 순서의 자유는 있지만 조사 과정에서 의미 있게 달라지는 경험은 제한적이다.

| 우선순위 | 판단 기준 |
| --- | --- |
| **P0** | 정상 행동으로 진행이 막히거나 핵심 조작 화면을 사용할 수 있음이 보장되지 않는 문제 |
| **P1** | 정답 노출, 잘못된 반응, 핵심 퍼즐의 증거 단절처럼 추리 경험을 직접 훼손하는 문제 |
| **P2** | 동선, 반복, 읽기, 감정선, 재플레이를 개선할 문제 |
| **P3** | 현재 기능과 서사 역할이 유효한 장면의 추가 개선 |

장면·퍼즐 표의 우선순위는 해당 행의 대표 과제 기준이다. 공통 모바일 가로 문제는 행별 우선순위와 별도로 P0으로 다룬다.

| 중간 결론 `s340` | 운영팀장으로 한정하거나 AI 전체 무죄를 고르면 재질문을 유도하도록 설계됐다. 실제로는 방문 사실만으로 계속이 열리고, 계속을 누르면 올바른 선택으로 돌아갈 수 없다. | ‘제어 경계까지 조사’만 다음 장면을 연다. 잘못된 선택의 효력은 엔딩 분기가 아니라 진행 장애다. |

## 검증 기록과 해석 범위

- 대표 배포본의 콘텐츠 JSON 11종이 원격 커밋의 파일과 바이트 단위로 일치했다. 원격 코드를 격리 복사본에서 실행했으며, 로컬 브랜치 작업 파일이나 프로덕션 설정을 변경하지 않았다.
- 장면 43개와 퍼즐 20개를 각각 데스크톱 1280×720, 모바일 가로 844×390에서 캡처했다. 기본 설정과 기존 150% 저장 설정을 따로 실행해 총 **252장**을 얻었다. 장면 캡처는 진입 화면, 퍼즐 캡처는 상호작용 시작 화면이다. 가로 폭 검사 통과는 세로 패널의 사용성을 보장하지 않았다.
- 모바일 기본 상태에서 20개 중 17개 퍼즐의 주요 패널 내부 높이가 11~56px로 줄어들었다. 공개심리 p04는 실제 배포본에서도 글자 크기 100%에서 **세 패널 모두 16px**였다. 이는 모바일 가로 가상 뷰포트 결과이며 실기기 입력, iOS Safari, 화면 낭독기의 전체 동작은 별도 확인이 필요하다.
- 정적 경로 37개가 검증을 통과했다. 이 검증은 정상 진행을 위한 선택과 퍼즐 제출을 가정하므로 비진행 항목의 UI에서 멈추는 사례를 포함하지 않는다. 정상 경로의 입력 자동화로 키보드 완주와 단축키 검증 2건, 퍼즐 20개의 오답·부분답 수정 상태 검증을 통과했다.
- 별도의 브라우저 테스트 5건으로 `s130`의 영상 미보유 제출 및 필수 요청 생략, `s340·s700` 진행 차단, `s530` 수신·거절, `s700` 두 정상 답변의 기록 차이를 재현했다. 노출된 분기 대사를 처리하지 않는 UI 코드와 실제 후속 화면도 대조했다.
- 의도된 흥미, 지루함, 감정의 효과는 설계 평가다. 실제 신규 플레이어의 이탈과 만족도를 측정하지 않았다. 검토 우선순위와 개선안은 제안이며 게임의 사건 정본이나 운영 정책을 바꾼 결정이 아니다.

### 수정 후 플레이 검증

처음 보는 플레이어에게 공략 없이 첫 공개심리까지 진행하게 한다. 첫 의문을 느낀 시점, 첫 정보 발견까지 걸린 시간, 선택 전 기대한 행동, 단서와 UI 중 어디에서 막혔는지, 증거를 보고 처음 생각을 바꾼 순간을 기록한다. 같은 빌드에서 승객 먼저와 회사 먼저를 각각 확인하고, 어떤 대사와 기록이 실제로 바뀌었는지 비교한다. 후반은 증거책을 여는 횟수와 틀린 항목 한 개를 교체하는 왕복을 비교한다. 마지막에는 플레이어가 자신이 찾아낸 모순과 자신의 선택 때문에 달라진 반응을 하나씩 설명할 수 있는지 확인한다.
